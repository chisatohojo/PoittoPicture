# ぽいっとピクチャ

大量の画像をフォルダ単位で読み込み、キーボード操作だけで高速にプレビュー、移動、削除扱いにできるローカル画像選別アプリです。

## 使い方

1. `dist/poitto-picture_v0.1.0_windows.zip` を展開します。
2. 展開したフォルダ内の `poitto-picture.exe` を起動します。
3. 画像フォルダを選択して、キーボードで画像を選別します。

## キー操作

- `Enter` / `右矢印` / `D`: 次の画像へ
- `左矢印` / `A`: 前の画像へ
- `Backspace` / `Delete`: 現在の画像をぽいっと削除

削除は完全削除ではなく、可能なら OS のゴミ箱へ移動します。ゴミ箱へ移動できない場合は、選択フォルダ内の `_deleted` フォルダへ退避します。

## 対応形式

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.bmp`
- `.gif`

大文字拡張子にも対応しています。

## 開発・再ビルド

```bat
build.bat
```

ビルド後、BOOTH などで配布しやすい zip が `dist/poitto-picture_v0.1.0_windows.zip` に出力されます。
