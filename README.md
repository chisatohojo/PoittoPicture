# ぽいっとピクチャ

大量の画像をフォルダ単位で読み込み、キーボード操作だけで高速にプレビュー、移動、削除扱いにできるローカル画像選別アプリです。

## 使い方

1. `dist/PoittoPicture.exe` を起動します。
2. 画像フォルダを選択します。
3. キーボードで画像を選別します。

## キー操作

- `Enter` / `右矢印` / `D`: 次の画像へ
- `左矢印` / `A`: 前の画像へ
- `Backspace` / `Delete`: 現在の画像をぽいっと削除

削除は完全削除ではなく、可能なら OS のゴミ箱へ移動します。ゴミ箱へ移動できない場合は、選択フォルダ内の `_deleted` フォルダへ退避します。

## 対応形式

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.bmp`
- `.gif`

大文字拡張子にも対応しています。

## 開発・再ビルド

```powershell
.\build_exe.ps1
```

ビルド後の exe は `dist/PoittoPicture.exe` に出力されます。
