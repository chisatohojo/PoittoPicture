ぽいっとピクチャ
================

概要
----
ぽいっとピクチャは、画像フォルダを選んで、キーボードだけで画像を確認・移動・削除扱いにできる Windows 向けの画像選別アプリです。

写真、スクリーンショット、AI生成画像などをテンポよく確認し、不要な画像を「ぽいっと」片付けるためのシンプルなツールです。


動作環境
--------
- Windows 10 / Windows 11
- Python のインストールは不要です
- インターネット接続は不要です


インストール方法
----------------
1. 配布 zip をダウンロードします。
2. zip ファイルを右クリックして「すべて展開」を選びます。
3. 展開したフォルダを好きな場所に置きます。

インストーラーはありません。展開するだけで使えます。


起動方法
--------
展開したフォルダ内の `poitto-picture.exe` をダブルクリックしてください。

起動すると画像フォルダを選ぶ画面が出ます。
画像が入っているフォルダを選ぶと、最初の画像が表示されます。


操作方法
--------
- Enter / 右矢印 / D / d: 次の画像へ
- 左矢印 / A / a: 前の画像へ
- Backspace / Delete: 現在の画像を削除扱いにする


削除仕様
--------
Backspace / Delete を押しても、画像はすぐに完全削除されません。

安全のため、次の順番で処理します。

1. 可能なら OS のゴミ箱へ移動します。
2. ゴミ箱へ移動できない場合は、選択した画像フォルダ内の `_deleted` フォルダへ移動します。

誤操作で即時完全削除されないようにしています。


注意事項
--------
- 大切な画像を扱う前に、念のためバックアップを取ってください。
- 壊れている画像や特殊な画像形式は表示できない場合があります。
- 初回起動時に Windows の警告が表示されることがあります。その場合は内容を確認してから起動してください。
- 本ソフトの使用によって発生した損害について、作者は責任を負いません。


開発者向け: 再ビルド方法
-----------------------
通常利用では、この作業は不要です。

ソースコードから exe と配布 zip を作り直す場合は、プロジェクトフォルダで次を実行してください。

```
build.bat
```

内部では PyInstaller を使って、コンソール画面が出ない Windows 用 exe を作成します。
生成される配布 zip は `dist/poitto-picture_v0.1.0_windows.zip` です。


アンインストール方法
--------------------
インストーラーは使用していません。

アンインストールしたい場合は、展開したフォルダごと削除してください。
