ぽいっとピクチャ 企画書
========================================

1. アプリ概要
----------------------------------------

「ぽいっとピクチャ」は、大量の画像をフォルダ単位で読み込み、キーボード操作だけで高速にプレビュー・移動・削除できるローカル画像選別アプリです。

AI画像生成結果、写真、スクリーンショット、素材画像などを、マウス操作なしでテンポよく確認し、不要な画像を「ぽいっと」片付けられることを目的とします。

アプリ名:
ぽいっとピクチャ

コンセプト:
かわいく、軽く、迷わず使える画像選別ツール

主な利用シーン:
- AI生成画像の候補整理
- 写真フォルダの不要画像削除
- スクリーンショット整理
- 投稿用・保存用画像の事前選別
- 大量画像の一次チェック


2. 開発目的
----------------------------------------

通常の画像ビューアやファイルエクスプローラーでは、画像を確認しながら削除する際に、マウス操作や複数ステップの操作が必要になり、作業テンポが落ちます。

本アプリでは、画像選別に必要な操作を最小限のキーに集約し、以下の体験を実現します。

- フォルダを選ぶだけで画像一覧を読み込める
- 現在の画像を大きくプレビューできる
- キーボードだけで次の画像・前の画像へ移動できる
- 不要な画像を即座に削除、または削除扱いにできる
- 誤削除を防ぐため、完全削除ではなく安全な削除方式を優先する


3. MVP範囲
----------------------------------------

初期実装では、以下の機能のみを実装します。

- フォルダ選択
- 画像ファイル一覧取得
- 画像プレビュー表示
- キーボード操作による画像移動
- キーボード操作による削除
- 現在位置、総枚数、ファイル名の表示
- 削除後の安全な表示更新
- 最後の画像削除時のエラー回避


4. 対象ファイル形式
----------------------------------------

初期対応する画像拡張子は以下とします。

- .jpg
- .jpeg
- .png
- .webp
- .bmp
- .gif

大文字拡張子にも対応してください。
例: .JPG, .PNG など


5. 基本仕様
----------------------------------------

5.1 起動時の動作

アプリ起動後、フォルダ選択ダイアログを表示します。
ユーザーがフォルダを選択したら、そのフォルダ内の画像ファイルを読み込みます。

フォルダ選択をキャンセルした場合は、アプリを終了して構いません。

画像が存在しないフォルダを選択した場合は、「画像がありません」のようなメッセージを表示します。


5.2 画像読み込み

選択フォルダ直下の画像ファイルを一覧化します。

初期実装では、サブフォルダ内の画像は対象外で構いません。

画像一覧はファイル名順にソートします。


5.3 画像プレビュー

現在選択中の画像をウィンドウ中央に表示します。

表示時の条件:
- 画像の縦横比を維持する
- ウィンドウサイズに収まるように縮小表示する
- 小さい画像は無理に拡大しすぎなくてよい
- 背景は黒、濃いグレー、または落ち着いた色を推奨

最低限、画像が見やすいことを優先してください。


5.4 情報表示

画面下部などに以下を表示します。

- 現在の画像番号
- 総画像枚数
- ファイル名

表示例:
12 / 158    sample_image_001.png


6. キーボード操作仕様
----------------------------------------

以下のキー操作に対応してください。

次の画像へ移動:
- Enter
- 右矢印
- D
- d

前の画像へ移動:
- 左矢印
- A
- a

現在の画像を削除:
- Backspace
- Delete

キー操作は、アプリウィンドウにフォーカスがある状態で動作するようにしてください。


7. 削除仕様
----------------------------------------

初期実装では、完全削除ではなく安全な削除方式を優先してください。

優先順位:
1. OSのゴミ箱へ移動
2. ゴミ箱移動が難しい場合、選択フォルダ内に「_deleted」フォルダを作成してそこへ移動
3. 完全削除は初期実装では避ける

Python実装の場合は、send2trash ライブラリの利用を推奨します。

想定:
pip install send2trash

削除操作後の挙動:
- 削除した画像を画像一覧から取り除く
- 次の画像を表示する
- 最後の画像を削除した場合は、残っている最後の画像を表示する
- 画像が0枚になった場合は、「画像がありません」などの表示にする
- クラッシュしないこと


8. 削除確認について
----------------------------------------

初期実装では、削除確認ダイアログは任意です。

推奨:
- まずは確認ダイアログなしで高速操作できる設計にする
- ただし安全のため、完全削除は禁止
- ゴミ箱移動、または _deleted フォルダ移動にする

将来的には設定で以下を切り替えられるとよいです。

- 削除確認あり
- 削除確認なし
- ゴミ箱へ移動
- _deleted フォルダへ移動


9. UI方針
----------------------------------------

アプリ全体はシンプルで軽量にしてください。

画面構成:
- 中央: 画像プレビュー
- 下部: ファイル名、現在位置、総枚数
- 任意: 簡単な操作ヘルプ

操作ヘルプ例:
← / A: 前へ
→ / D / Enter: 次へ
Backspace / Delete: ぽいっと削除

かわいい雰囲気のアプリ名ですが、初期実装では装飾よりも使いやすさと軽快さを優先してください。


10. アイコン方針
----------------------------------------

アプリアイコンは、以下の方向性を想定します。

アイコン案:
青いかわいいゴミ箱に、写真サムネイルをぽいっと投げ入れているシンプルなドット絵アイコン。

デザイン要素:
- 青い小さなゴミ箱
- ゴミ箱にはかわいい表情
- 空中に写真サムネイル
- 写真が投げ込まれる動きを示すピンク色の軌跡
- パステルカラー
- シンプルなドット絵
- 角丸スクエアのアプリアイコン向き構図

初期実装ではアイコン設定は必須ではありません。
後から差し替え可能な構成にしてください。


11. 非機能要件
----------------------------------------

- ローカル環境で動作すること
- インターネット接続を必要としないこと
- 100枚以上の画像でも操作が重くなりすぎないこと
- 画像切り替え時にクラッシュしないこと
- 削除済みファイルを参照し続けないこと
- 画像読み込みエラーが発生した場合でも、アプリ全体が落ちないこと


12. エラー処理
----------------------------------------

以下のケースを考慮してください。

- フォルダ選択がキャンセルされた
- 選択フォルダに画像がない
- 画像ファイルが壊れていて読み込めない
- 削除対象ファイルがすでに存在しない
- 削除または移動に失敗した
- _deleted フォルダに同名ファイルが存在する

同名ファイルが存在する場合は、ファイル名の末尾に連番を付けて衝突を避けてください。

例:
image.png
image_1.png
image_2.png

15. 成功条件
----------------------------------------

初期実装の成功条件は以下です。

- アプリ起動後、フォルダを選択できる
- 選択フォルダ内の画像が表示される
- Enter、右矢印、Dキーで次の画像へ移動できる
- 左矢印、Aキーで前の画像へ移動できる
- Backspace、Deleteキーで現在画像を安全に削除扱いにできる

- 最後の画像削除時にもクラッシュしない
- 画像が0枚になったときに破綻しない
- 100枚程度の画像で実用的に操作できる


16. Codexへの実装依頼文
----------------------------------------

以下の仕様で、ローカルPC向けの画像選別アプリ「ぽいっとピクチャ」を実装してください。

目的:
大量の画像をフォルダ単位で読み込み、キーボード操作だけで高速にプレビュー、移動、削除できるようにする。

基本仕様:
- 起動時にフォルダ選択ダイアログを表示する
- 選択フォルダ内の画像ファイルを読み込む
- 対象拡張子は jpg, jpeg, png, webp, bmp, gif
- 大文字拡張子にも対応する
- 画像を中央にプレビュー表示する
- 画像はウィンドウサイズに合わせて縮小し、縦横比を維持する
- 現在のファイル名、現在位置、総枚数を表示する
- Enter / 右矢印 / D / d で次の画像へ移動する
- 左矢印 / A / a で前の画像へ移動する
- Backspace / Delete で現在の画像を削除扱いにする
- 削除は完全削除ではなく、可能ならOSのゴミ箱へ移動する
- ゴミ箱移動が難しい場合は、選択フォルダ内の _deleted フォルダへ移動する
- 削除後は次の画像を表示する
- 最後の画像を削除した場合もエラーにならないようにする
- 画像が0枚になった場合もクラッシュしないようにする

初期リリースでは、画像編集、タグ付け、サムネイル一覧、AI判定などは不要です。
まずはシンプルで軽快に動作するMVPを作成してください。

可能であれば、Pythonで実装してください。
GUIは Tkinter、PySide6、PyQt6 など、実装しやすいものを選んで構いません。
画像表示には Pillow などを利用して構いません。
安全な削除には send2trash の利用を推奨します。


17. 備考
----------------------------------------

このアプリは「画像ビューア」ではなく、「画像選別専用ツール」です。

最優先する体験:
- 見る
- 次へ進む
- 戻る
- 不要画像をぽいっと片付ける

余計な機能を増やすより、軽快で迷わない操作感を重視してください。
